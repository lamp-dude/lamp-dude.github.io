ESCALATE is a work-in-progress police chase game set in the Midwest, in a fictional town inspired by where I live called Cartanville. Players must survive as long as possible as pursuits escalate. Currently the game features arcade-style driving physics, destructible environments, smart traffic, and a police system, with more systems and the map still in development. Made in Unity3D URP.
