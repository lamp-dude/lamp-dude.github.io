Window Cleaner is a game that I made with my team during our time at the UIUC WYSE Game Design summer program. The theme and limitation required that it be “playable” on an early Game Boy, so we had to use a limited game engine. When I got back home, I recreated it using Unity2D to learn more about 2D games in Unity and make it more fun.
